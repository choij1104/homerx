Full description (≤4000):
```
HomeRxは、米国の薬局で売られている市販薬（OTC）とサプリメントを、日本語・英語・韓国語で説明するガイドです。

移住者、高齢の方、介護する家族、留学生など、薬局の棚の前で英語のラベルが分かりにくい方のために作りました。HomeRxは教育用の参考資料です。診断や処方は行わず、薬剤師や医師の代わりにはなりません。

Drug Factsを日本語で
• 82項目：痛み・発熱、アレルギー、かぜ・せき、鼻、目・耳、胃腸、便秘、乗り物酔い、皮膚、応急手当、口腔、睡眠、女性の健康、禁煙、ビタミン・ミネラル・ハーブのサプリ
• 薬ごとに米国のDrug Factsラベルと同じ順番で整理：有効成分、効能、警告、用法、使用をやめて医師に相談するとき
• 各項目に出典（DailyMedのラベル、NIH栄養補助食品局、NCCIH、CDC）と確認日を表示
• サプリは推奨量、上限、研究の結果、相互作用のある薬を表示

わたしの薬箱
• 家にある薬を入れると、同じ成分の重複（例：アセトアミノフェンが2つ）、同じ種類の薬の重ね飲み（NSAID鎮痛薬2つ、眠くなる抗ヒスタミン薬2つ）、チェックした健康状態に当てはまるラベルの警告を知らせます
• 使用期限の管理

日本・韓国で使っていた薬
• ロキソニンS、イブA錠、バファリンA、ガスター10、アレグラFX、韓国のタイレノール500などの成分を見て、米国で同じ成分を処方なしで買えるか確認できます

知っておく
• Drug Factsラベルの読み方、液剤の量り方、古い薬の捨て方、高齢者・持病のある方の注意、サプリの安全
• 薬剤師に見せる英語のフレーズ

プライバシーとオフライン
アカウント、広告、分析、追跡はありません。薬箱と設定はスマートフォンの中だけに保存されます。インターネットなしで動き、大きな文字も選べます。

安全
初めて使うときに選んだ言語で短い案内を表示します。緊急番号はいつでもワンタップ：911、中毒センター 1-800-222-1222、988 自殺・危機相談。

重要
HomeRxは教育資料であり、医学的助言、診断、治療ではなく、医療機器でもありません。薬やサプリを使う前には製品のラベルを読み、薬剤師や医師に相談してください。妊娠・授乳中、子どもに与えるとき、65歳以上、持病がある、他の薬を飲んでいる場合は特にそうしてください。緊急時は911に電話してください。

テキサス州のHAKOYA LLCが作りました。
```
