Full description (≤4000):
```
HomeRxは、米国の薬局で売られている市販薬（OTC医薬品）とサプリメント（dietary supplement）を、日本語・英語・韓国語で理解するためのガイドです。

移住者、高齢者、介護者、留学生、地域団体など、薬局の棚の前で英語の表示や成分名がわかりにくい方のために作りました。HomeRxは教育用のリファレンスです。診断や処方は行わず、薬剤師や医師の代わりにはなりません。薬局でより安全に質問できるようにお手伝いします。

内容
• 症状別のOTC医薬品：かぜ・咳、アレルギー、痛み・発熱、胃腸、皮膚、睡眠、目・耳、口腔、女性、小児、めまい、痛風、応急処置
• 各医薬品について：成分名、米国薬局で見るブランド名、主な用途、使う前の安全確認
• サプリメント：根拠の強さの表示、主な用途、相互作用と注意点
• 高齢者・持病のある方の安全チェック：第一世代抗ヒスタミン薬、鼻づまり薬、NSAID鎮痛薬、一部のサプリメントと、年齢・高血圧・抗凝固薬・肝臓や腎臓の病気との関係
• 成分の重複：かぜ薬、鎮痛薬、睡眠補助薬を一緒に使うと、acetaminophen、NSAID、抗ヒスタミン薬が重なることがあります
• OTCで様子を見てはいけない場合：すぐに911に電話すべき症状と、今日中に受診・薬剤師相談が必要な症状
• 薬剤師に見せる英語フレーズ：スマートフォンの画面をそのまま見せられます

使いやすさ
• 症状、成分、ブランド名で検索（例：Tylenol、ibuprofen、allergy、melatonin）
• カテゴリで絞り込み、カードをタップすると詳細が開きます
• 日本語・英語・韓国語をいつでも切り替えられ、すべての項目が3言語で読めます
• オフラインで動作します。アカウント、登録、広告、トラッキングはなく、個人情報を収集・保存しません

安全を第一に
最初に、選んだ言語で短い免責事項を表示し、教育用資料であることを確認していただきます。画面上部には緊急番号を常に表示します：緊急時は911、中毒・過量服用は1-800-222-1222、メンタルヘルスの危機は988。

アプリが参考基準として挙げている資料：FDA OTC Monographs、DailyMed、MedlinePlus、NIH Office of Dietary Supplements、NIH LiverTox、CDC、Poison Control。

ご注意
HomeRxは教育用のリファレンスであり、医学的助言、診断、治療ではなく、医療機器でもありません。薬やサプリメントを使う前には製品の表示を読み、薬剤師または医師に相談してください。妊娠中・授乳中の方、子どもに使う場合、65歳以上の方、持病のある方、ほかの薬を使っている方は特にご注意ください。緊急時は911に電話してください。

HomeRxは米国テキサス州サンアントニオのHAKOYA LLCが開発しました。
```
